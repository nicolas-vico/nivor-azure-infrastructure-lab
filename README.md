# Nivor Systems | Azure Enterprise Infrastructure

> Enterprise Azure infrastructure project designed to simulate a real production environment while preparing for the Microsoft AZ-104: Azure Administrator Associate certification.

---

## Overview

**Nivor Systems** is a fictional technology company created to simulate the design, deployment and administration of a real enterprise Azure environment.

The purpose of this project is to gain practical experience with Microsoft Azure by designing, implementing and documenting a production-like infrastructure following Microsoft best practices.

Rather than completing isolated laboratory exercises, this repository documents the progressive implementation of an Azure environment based on realistic business scenarios.

---

## Objectives

- Build a complete Azure enterprise infrastructure from scratch.
- Gain hands-on experience with Azure administration.
- Apply Microsoft best practices for governance, security and operations.
- Develop troubleshooting and operational skills.
- Document every implementation in a professional manner.
- Build a GitHub portfolio demonstrating Azure administration skills.
- Prepare for the Microsoft AZ-104 certification.

## Learning Methodology

Each implementation follows the same workflow:

1. Study the Azure concept.
2. Understand the business requirement.
3. Design the solution.
4. Deploy the infrastructure.
5. Validate the implementation.
6. Document technical decisions.
7. Review security and cost implications.
8. Answer interview-style and AZ-104 examination questions.

This methodology is designed to replicate the daily work of a Junior Azure Administrator rather than simply completing isolated laboratory exercises.
