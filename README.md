# Nivor Systems - Azure Enterprise Infrastructure

> Enterprise Azure infrastructure project built while preparing for the Microsoft AZ-104 certification.

---

## Overview

**Nivor Systems** is a fictional company created to simulate the deployment and administration of a real enterprise Azure environment.

The goal of this project is not only to prepare for the **Microsoft AZ-104: Azure Administrator Associate** certification, but also to develop practical skills required for junior Azure infrastructure and cloud administration roles.

Throughout this project, the Azure environment is progressively designed, implemented and documented following Microsoft best practices and real-world business scenarios.

---

## Objectives

- Build a complete Azure enterprise environment from scratch.
- Gain hands-on experience with Azure administration.
- Apply Microsoft best practices.
- Develop troubleshooting and operational skills.
- Produce technical documentation suitable for a professional portfolio.
- Prepare for the AZ-104 certification.

## Learning Methodology

Each section of the project follows the same workflow:

1. Study the Azure concept.
2. Understand the business requirement.
3. Design the solution.
4. Deploy the infrastructure.
5. Validate the implementation.
6. Document technical decisions.
7. Review costs and security.
8. Answer interview-style questions.

This methodology aims to replicate the work of a Junior Azure Administrator in a production environment rather than simply completing isolated laboratory exercises.
